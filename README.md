This code belongs to clients, so it's private. Happy to walk you through any of it.

AI agents (Claude Code) type a lot of my code. The requirements, the data model, the rules, the review, the tests and the checks in production are mine. I'm upfront about it because it's how I work, and I'm practising writing more by hand so I can explain every line.

**Stack:** TypeScript, React, Next.js, PostgreSQL, Supabase, Stripe, Tailwind CSS, AI SDK, Vitest, Vercel, GitHub Actions
